# Shadow Swap - OS Concept Map

Search the project for `# OS CONCEPT:` to find every implementation. Press **F3** in game to see a live monitor for all 8 concepts.

| OS Concept | Implementation in Shadow Swap | Script / Scene | Function or Code | Demonstration |
|---|---|---|---|---|
| Processes and Programs | Scenes are "programs" saved on disk; `instantiate()` creates a running copy at runtime: the player, every memory shard, Shadow Wisps (timer), burst effects, player echo trail, HUD, pause menu, end screen. | `scenes/levels/level.gd`, `scenes/player/player.gd`, `memory_shard.tscn`, `shadow_wisp.tscn`, `burst_effect.tscn`, `player_echo.tscn` | `_create_player()`, `_spawn_shards()`, `_spawn_wisp()`, `_spawn_burst()`, `_spawn_echo()` | Press F3: "PROCESSES spawned / freed / alive" rises as you walk (echoes), collect shards and shift realms. |
| CPU Scheduling | `_physics_process(delta)` = fixed 60/s tick (movement, collision). `_process(delta)` = once per rendered frame (animation, fades, stage timer, loading-bar polling). `delta` makes speed independent of frame rate. | `player.gd`, `level.gd`, `hud.gd`, `shadow_wisp.gd`, `loading_screen.gd` | `ShadowSwapPlayer._physics_process()`, `Level._process()` | F3 shows FPS, physics ticks/s, and process-frame vs physics-frame counters. |
| Interrupts | Signals. Built-in: `body_entered`, `timeout`, `pressed`, `node_added`. Custom: `collected`, `touched_player`, `retired`, `realm_changed`, `shard_count_changed`, `stage_completed`, `pause_requested`, `resumed`, `restart_requested`, `menu_requested`, `next_requested`, `cleanup_mode_changed`. All are connected **in code** with `.connect()`. | `level.gd`, `memory_shard.gd`, `shadow_wisp.gd`, `hud.gd`, `pause_menu.gd`, `stage_end_screen.gd`, `audio_manager.gd` | `Level._connect_signals()`, `shard.collected.connect(_on_shard_collected)`, `get_tree().node_added.connect(...)` | Collect a shard or shift realm: F3 "INTERRUPTS last signal" shows which signal fired and which function handled it. |
| I/O Management | **Polling:** `Input.get_vector()` asks every physics tick which movement keys are held. **Event-driven:** `_unhandled_input(event)` reacts only when SPACE, E, R, ESC, M or F-keys are pressed. | `player.gd`, `level.gd`, `pause_menu.gd`, `audio_manager.gd`, `debug_overlay.gd` | `_physics_process()` (polling), `_unhandled_input()` (events) | F3 shows "polled move (x, y)" updating live and "last event" changing on key presses. |
| Memory Management | Temporary objects (echo trail, bursts, wisps) are freed with `queue_free()` through `GameState.dispose()`; collected shards free themselves; sound effects use a **pool** of 8 re-used `AudioStreamPlayer`s. F4 switches cleanup OFF to reproduce the "before" (leaking) behaviour for the report. | `autoload/game_state.gd`, `player_echo.gd`, `burst_effect.gd`, `shadow_wisp.gd`, `memory_shard.gd`, `audio_manager.gd` | `GameState.dispose()`, `queue_free()`, `AudioManager.play_sfx()` | See `docs/MEMORY_REPORT.md`. F3 shows nodes / orphans / static memory live. |
| File Systems | Progress (unlocked stage, best times, shards, mute) saved as JSON in `user://shadow_swap_save.json`. Missing, unreadable, non-JSON or wrongly-typed data falls back to safe defaults (never crashes). | `autoload/save_manager.gd`; `scenes/ui/main_menu.gd` | `save_progress()`, `load_progress()`, `_sanitize()`, `record_stage_clear()`, `delete_save()` | Clear Stage 1, close the game, reopen: CONTINUE shows Stage 2. SYSTEM INFO > ERASE SAVE then restart: no crash, CONTINUE is greyed out. |
| Threads | The loading screen requests the next stage with `ResourceLoader.load_threaded_request()`, polls `load_threaded_get_status()` every frame (progress bar), then `load_threaded_get()` and changes scene on the main thread. | `scenes/ui/loading_screen.gd` | `_ready()`, `_process()`, `_finish_loading()` | PLAY / CONTINUE / NEXT STAGE shows the loading bar; F3 "THREADS" shows load time in ms. |
| OS as a Platform | `OS.get_name()`, `OS.get_version()`, `OS.get_processor_name()`, `OS.get_user_data_dir()`, `OS.has_feature("template")` (editor vs exported), `OS.shell_open()` to open the save folder. Export presets for Windows and Linux are included. | `autoload/platform_info.gd`; `main_menu.gd`; `export_presets.cfg` | `PlatformInfo.get_summary()`, `open_save_folder()` | MAIN MENU > SYSTEM INFO. Export (see README) and run the .exe outside Godot: it shows "Exported build". **Export not performed yet - see README.** |
